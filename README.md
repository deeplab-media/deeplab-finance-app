# Deeplab Finance

App quản lý tài chính dự án cho agency sản xuất video — 1 file HTML, chạy hoàn toàn trên trình duyệt.

- **Không chứa dữ liệu nào trong repo này.** Số liệu nằm trong trình duyệt của người dùng và (nếu bật đồng bộ) trong repo **private** `deeplab-finance-data`.
- Dùng trên iPhone: mở trang GitHub Pages của repo này bằng Safari → Chia sẻ → **Thêm vào MH chính**.
- Đồng bộ thiết bị: tab *Chi phí cố định* → *Đồng bộ điện thoại ↔ máy tính* → dán fine-grained PAT (chỉ quyền Contents của repo `deeplab-finance-data`).
